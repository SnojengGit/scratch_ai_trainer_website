6. Export



Easiest. A ready project with the code that runs the model and your weights already inside.
Open it in Scratch (File > Load from your computer) or TurboWarp, click the green flag, then click the box and type a start.



Only the numbers. A plain Scratch list cannot do anything with them by itself: import this file into the MODEL list of a project
that already has the reader code (the .sb3 above, or the tutorial project). Tick MODEL in the Variables blocks, right-click the list on the stage,
choose import, pick the file, then click the green flag.


Format (one item per line): SCRATCHGPT, d, layers, heads, context, vocab size, MLP size, then the vocab as character codes (10 = new line), then every weight.


 For your own code (Python, JS...).



7. Building it yourself in Scratch


The tutorial project shows how to build the Scratch side block by block. You will need this text for the ALPHA variable
(every character the model can use, in order). Press Copy, then paste it into a set ALPHA to block.


  


Test while you build: type the same start text you will use in Scratch, press Show numbers, and compare.
Each row says which block to click and what your list or variable should show. Small differences in the last digit are fine.
